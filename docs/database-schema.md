# Database schema

MySQL 8+ (utf8mb4). All tables have `id` and timestamps unless noted. Migrations: `database/migrations/2026_11_08_*`.

## Content

| Table                   | Purpose                                                            | Key columns                                                                                                                                                                                                                         | Relations and indexes                                                                                                                             |
| ----------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `profiles`              | Single row: owner's identity, hero, contact details and About copy | `full_name`, `designation`, `hero_title`, `hero_subtitle`, `summary`, `years_experience`, `years_primary_stack`, `hero_technologies` (json), `availability_enabled`, `availability_text`, About Markdown fields, `languages` (json) | `photo_media_id` → `media` (null on delete)                                                                                                       |
| `experiences`           | Employment history                                                 | `company`, `title`, `employment_type`, `start_date`, `end_date`, `is_current`, `description` (md), `responsibilities` (json), `contributions` (json), `is_published`, `sort_order`                                                  | index (`is_published`, `start_date`)                                                                                                              |
| `experience_technology` | Pivot                                                              | `experience_id`, `technology_id`                                                                                                                                                                                                    | composite PK, cascade on delete                                                                                                                   |
| `technologies`          | Shared technology list                                             | `name` (unique), `slug` (unique), `url`                                                                                                                                                                                             |                                                                                                                                                   |
| `project_categories`    | Project grouping and filters                                       | `name`, `slug` (unique)                                                                                                                                                                                                             |                                                                                                                                                   |
| `projects`              | Projects and case studies                                          | `title`, `slug` (unique), `client`, `summary`, `contribution`, `status` (draft/published), `published_at`, `is_featured`, 12 case-study Markdown columns, `links` (json), `meta_title`, `meta_description`                          | `project_category_id` → categories (null on delete), `thumbnail_media_id` → media (null on delete); index (`status`, `is_featured`, `sort_order`) |
| `project_technology`    | Pivot                                                              | `project_id`, `technology_id`                                                                                                                                                                                                       | composite PK, cascade                                                                                                                             |
| `project_images`        | Gallery (screenshots and diagrams)                                 | `kind`, `caption`, `sort_order`                                                                                                                                                                                                     | `project_id` cascade, `media_id` cascade; index (`project_id`, `sort_order`)                                                                      |
| `skill_categories`      | Skill groups                                                       | `name`, `slug` (unique), `is_published`                                                                                                                                                                                             |                                                                                                                                                   |
| `skills`                | Individual skills                                                  | `name`, `is_published`                                                                                                                                                                                                              | `skill_category_id` cascade; unique (`skill_category_id`, `name`)                                                                                 |
| `principles`            | "Engineering approach" blocks                                      | `title`, `icon`, `body` (md)                                                                                                                                                                                                        |                                                                                                                                                   |
| `education`             | Degrees                                                            | `institution`, `degree`, `subject`, `start_year`, `graduation_year`, `grade`                                                                                                                                                        |                                                                                                                                                   |
| `certifications`        | Certifications, training, awards                                   | `name`, `issuer`, `type`, `issued_on`, `expires_on`, `credential_id`, `credential_url`                                                                                                                                              |                                                                                                                                                   |
| `posts`                 | Optional blog                                                      | `title`, `slug` (unique), `excerpt`, `body` (md), `status`, `published_at`                                                                                                                                                          | `cover_media_id` → media (null on delete); index (`status`, `published_at`)                                                                       |

## Site structure

| Table              | Purpose                                                             | Notes                                                                                                              |
| ------------------ | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `page_sections`    | Homepage sections: on/off, order, eyebrow/heading/intro             | `key` unique (about, experience, projects, skills, approach, education, contact)                                   |
| `navigation_items` | Header and footer menus                                             | `location` (header/footer), `url`, `open_in_new_tab`, `is_visible`; index (`location`, `is_visible`, `sort_order`) |
| `social_links`     | Profiles shown in hero, contact and footer, and in JSON-LD `sameAs` | `platform`, `show_in_hero`, `is_published`                                                                         |
| `seo_settings`     | Per-page title, description, share image, noindex                   | `page_key` unique; `og_image_media_id` → media (null on delete)                                                    |
| `website_settings` | Key/value settings (JSON values)                                    | `key` unique. Known keys and defaults: `App\Services\Settings::DEFAULTS`                                           |

## Media, messages and users

| Table              | Purpose                           | Notes                                                                                                                                            |
| ------------------ | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `media`            | Uploaded images                   | `disk`, `directory`, `filename`, `variants` (json: `webp`, `thumb`), `width`, `height`, `alt`, `caption`; `uploaded_by` → users (null on delete) |
| `contact_messages` | Contact form submissions          | `name`, `email`, `subject`, `message`, `ip_address`, `user_agent`, `read_at`; indexes on `read_at`, `created_at`                                 |
| `users`            | Starter kit table plus `is_admin` | `is_admin` is not mass assignable                                                                                                                |

Framework tables from the starter kit: `password_reset_tokens`, `sessions`, `cache`, `cache_locks`, `jobs`, `job_batches`, `failed_jobs`, `passkeys`.

## Delete behaviour

- Deleting **media** detaches it from profiles, projects (thumbnail), posts and SEO pages (set to null), and removes gallery rows that use it.
- Deleting a **project** removes its gallery rows and technology links.
- Deleting a **technology** removes it from projects and experiences.
- Deleting a **project category** leaves its projects uncategorised.
- Deleting a **skill category** deletes its skills.
